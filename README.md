# Морфологический анализатор и синтезатор глаголов русского языка

Этот проект представляет собой инструмент для морфологического анализа и синтеза форм глаголов русского языка. Он сочетает в себе возможности статистической библиотеки `pymorphy3` и правилоподобных конечных преобразователей (`pynini`), чтобы обеспечить точную обработку сложных явлений русской глагольной морфологии, таких как вид, время, спряжение, чередования и возвратность.

## Функциональность

- **Синтез**: По инфинитиву глагола генерирует все его формы (настоящее, прошедшее, будущее время, возвратные формы).
- **Анализ**: По словоформе определяет инфинитив, время, вид, лицо/число/род, а также указывает, является ли глагол совершенного или несовершенного вида (или двувидовым).
- **Обработка сложного будущего времени**: Корректно распознаёт и генерирует конструкции типа "буду читать".
- **Поддержка возвратных глаголов**: Обрабатывает формы с частицей `-ся/-сь`.
- **Фильтрация архаизмов и просторечий**: Исключает формы, не соответствующие литературной норме (например, "хочут", "побежу").
- **Гибридный подход**: Использует как словарные данные (`pymorphy3`), так и правила (`FST`), обеспечивая баланс между точностью и покрытием.

## Технологии

- **Python 3**
- **[pymorphy3](https://github.com/no-plagiarism/pymorphy3)**: для начального морфологического анализа и получения эталонных данных.
- **[pynini](https://github.com/kylebgorman/pynini)**: для построения конечных преобразователей, моделирующих морфологические правила.
- **Dataclasses**: для структурирования данных о формах глаголов.

## Структура проекта

- `VerbProcessor`: Враппер вокруг `pymorphy3` для анализа и синтеза.
- `SimpleFST`: Класс, реализующий простой FST для генерации форм на основе правил и словарей.
- `FSTProcessor`: Класс, который обучает FST на данных `pymorphy3` и использует его для анализа/синтеза.
- `main_loop()`: Интерактивный CLI для тестирования функциональности.
